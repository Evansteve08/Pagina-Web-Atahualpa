 Hacienda Atahualpa — Sitio Web & Menú Interactivo

Bienvenido al repositorio oficial del sitio web de Hacienda Atahualpa, un restaurante de comida criolla y centro de eventos ubicado en Bogotá (Usme). Este proyecto combina una experiencia visual inmersiva para los clientes con un sistema backend en tiempo real para la gestión del menú y reservas.

 Características Principales

 Carta & Menú Dinámico

Filtros por Categoría: Visualización por Bandejas Especiales, Sopas y Porciones.

Conexión a Base de Datos en Tiempo Real: Los platos y precios se cargan directamente desde Supabase. Si el administrador cambia un precio o elimina un plato, se actualiza al instante para todos los clientes.

 Carrito de Compras integrado a WhatsApp

Agregado dinámico de platos con selección de cantidades.

Cálculo de total en pesos colombianos (COP).

Envío automático del pedido estructurado directamente al número oficial de WhatsApp del restaurante.

Sistema de Reservas

Formulario para reserva de mesas y eventos especiales.

Almacenamiento directo de la reserva en Supabase y notificación simultánea por correo electrónico utilizando Formspree.

 Panel de Administración (CRUD + Auth)

Autenticación Segura: Inicio de sesión exclusivo con Supabase Auth.

Gestión Completa de Menú: Crear, editar y eliminar platos existentes directamente desde el panel emergente en la web sin tocar una sola línea de código.

 Tecnologías Utilizadas

Frontend: HTML5, CSS3 (Variables CSS, Flexbox, CSS Grid), JavaScript (ES6+ Vanilla).

Backend & Base de Datos: Supabase (PostgreSQL & Row Level Security).

Autenticación: Supabase Auth (@supabase/supabase-js v2).

Formularios: Formspree API para recepción de notificaciones de correo.

Iconografía & Tipografía: FontAwesome 6, Google Fonts (Poppins & Playfair Display).

 Configuración del Backend (Supabase)

Para poner en marcha el sitio con tu propia base de datos:

1. Tablas en PostgreSQL (SQL Editor)

-- Tabla de Productos / Carta
CREATE TABLE productos (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  nombre TEXT NOT NULL,
  categoria TEXT NOT NULL,
  precio INTEGER NOT NULL,
  descripcion TEXT NOT NULL,
  imagen TEXT NOT NULL
);

-- Tabla de Reservas
CREATE TABLE reservas (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  nombre TEXT NOT NULL,
  email TEXT NOT NULL,
  telefono TEXT NOT NULL,
  personas INTEGER NOT NULL,
  fecha TEXT NOT NULL,
  hora TEXT NOT NULL,
  notas TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Políticas de Seguridad (RLS)
ALTER TABLE productos ENABLE ROW LEVEL SECURITY;
ALTER TABLE reservas ENABLE ROW LEVEL SECURITY;

-- Permisos para productos
CREATE POLICY "Lectura pública de productos" ON productos FOR SELECT USING (true);
CREATE POLICY "Edición solo para admin" ON productos FOR ALL USING (auth.role() = 'authenticated');

-- Permisos para reservas
GRANT USAGE ON SCHEMA public TO anon, authenticated;
GRANT INSERT ON TABLE public.reservas TO anon, authenticated;
CREATE POLICY "Permitir crear reservas públicas" ON public.reservas FOR INSERT TO anon, authenticated WITH CHECK (true);


2. Variables de Entorno en script.js

Reemplaza tus credenciales obtenidas en Project Settings > Data API & API Keys:

const SUPABASE_URL = 'https://tu-proyecto.supabase.co';
const SUPABASE_ANON_KEY = 'tu-llave-anon-public-aqui';
